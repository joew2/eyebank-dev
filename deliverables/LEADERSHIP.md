# Leadership page

`/who-leads-the-eye-bank/` uses the **EyeDonation Leadership** template and native editable Image, Heading, and Paragraph blocks. The supplied copy is preserved. Four EyeDonation.org links use relative paths so they stay on the current installation; email and Donate Life registry links retain their supplied destinations. The supplied header photo is bundled under `assets/leadership/` for portable installation.

The layout shares Home/About typography, blue headings, and 1050px content width. Replace the photo or edit text and links in the page editor.

Reuse the **EyeDonation Leadership** pattern on another page. The **EyeDonation Saved Leadership Layout** template is an independent backup layout. The normal template displays editable page content.

On another installation, install the theme and migration plugin, then preview and run **021_install_leadership** in Tools → Site Migrations. Save a recoverable database backup before replacing existing content. The migration records before-images and retains legacy builder data. Completed runs preserve later edits.

# Mobile Resources card height follow-up

1. Install **16-custom-mobile-resource-card-height-1.1.0.zip** over the existing plugin (choose Replace current with uploaded) and activate **Custom Mobile Resource Card Height CWS**.
2. Open **Tools → Mobile Resource Card Height CWS**.
3. Check the agreement and click **Process all updates**.
4. Clear the site/CDN cache and check the Resources cards on a phone.

Run this after the desktop/mobile image replacement plugin. No new images or theme upload are needed.

The recipients/families card matches the other two cards: 300px on phones and 420px in the wider stacked layout. The mobile photo is cropped 30 CSS pixels from the top; the remaining excess is cropped from the bottom. Desktop is unchanged. Applied and verified locally.

This update runs even when version 1.0.0 was already processed.

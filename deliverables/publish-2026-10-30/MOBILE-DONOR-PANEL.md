# Mobile donor panel adjustment

1. Install **13-custom-mobile-donor-panel-1.0.0.zip** as a new plugin and activate **Custom Mobile Donor Panel CWS**.
2. Open **Tools → Mobile Donor Panel CWS**.
3. Check the backup agreement and click **Process all updates**.
4. Clear site/CDN caches and check the homepage on a phone.

The entire card is 20% smaller on mobile/tablet and sits 12px above the hero's bottom edge, clearing Grayson's face. Desktop is unchanged. The migration only adds scoped CSS, preserving the image, page content, donor link and unrelated site settings. No theme update is needed. The fix is already applied locally.

Once verified, you may deactivate this migration plugin; the saved adjustment remains.

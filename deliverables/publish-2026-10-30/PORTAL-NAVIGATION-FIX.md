# Move portal links to the blue bar

1. Install **08-custom-portal-navigation-fix-1.0.0.zip** as a new plugin and activate **Custom Portal Navigation Fix CWS**.
2. Open **Tools → Portal Navigation Fix CWS**.
3. Check the backup agreement and click **Process all updates**.
4. Wait for completion, clear the site cache, then refresh the public site.

The two portal buttons are removed from beside EyeCanSeeAgain.org and placed between Give Now and More in the actual active blue-bar menu, whether inline or a saved Main/ED Primary record. Other menu entries and existing page content are preserved. No theme update is needed. The applied correction remains if you deactivate the plugin afterward.

Keep the older migration/repair plugins inactive during this correction. Do not rerun an unfinished older header migration afterward, because that could restore its older layout.

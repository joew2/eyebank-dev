# Homepage-only restore

1. Install **09-custom-homepage-restore-1.0.0.zip** as a new plugin and activate **Custom Homepage Restore CWS**.
2. Open **Tools → Homepage Restore CWS**.
3. Confirm the displayed page is the intended homepage. If needed, select the existing static homepage under Settings → Reading.
4. Check the backup agreement and click **Restore homepage**. Keep the tab open until it finishes.
5. Clear the site cache and review the homepage.

This reinstalls the latest supplied editable homepage and repairs its display templates. It keeps the current header, navigation, footer and other pages intact. No theme update or old migration rerun is required, provided the current EyeDonation theme/assets remain installed.

The plugin is independent of old completion history. You can use the same button for another restore in the future; each new completed run has fresh content before-images. An interrupted run resumes its existing checkpoints. Activation alone does not change the site. Keep earlier migration/repair processors inactive while restoring.

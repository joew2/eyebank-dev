# Transplant Recipients & Donor Families

Page: `/transplant-recipients-donor-families/`.

Edit the page in WordPress using its native blocks. The pale-blue introduction and two resource columns share the Home/About typography and 1050px content width. Columns stack on mobile.

The reusable pattern is **EyeDonation Transplant Recipients and Donor Families**. The **EyeDonation Saved Recipients and Families Layout** template provides an independent backup layout; the normal template displays editable page content.

For another installation, install the updated theme and migrations plugin, then preview and apply migration **019_install_recipients_families** under Tools → Site Migrations. Review the preview and save a database backup before replacing existing content. Completed runs do not overwrite subsequent edits.

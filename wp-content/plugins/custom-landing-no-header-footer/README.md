# Custom Landing No Header Footer CWS

Install and activate, then open Tools → Landing No Header Footer CWS. Check the backup agreement and click Process all updates. Activation alone changes nothing.

Creates the WordPress block template “Landing Page No Header and Footer” and assigns it to the existing /fall-benefit/ page by slug, without hardcoded page IDs. Requires the EyeDonation theme. The template renders Post Content with a full-width, zero-padding main wrapper and no title, header, logo, navigation, member bar or footer. The normal WordPress content rendering pipeline and Thrive content filters remain available. Page content and all Thrive metadata are preserved. WordPress head/footer asset hooks remain provided by the block theme runtime.

The original template assignment and any existing template content are saved in cwslnhf_history. Completed retries preserve later edits. After successful migration, deactivate this plugin; the saved template and assignment remain. You may select this template on other pages in the page editor.
